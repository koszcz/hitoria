Claude can now play the game as one of four tester personas, with `/playtest`. Each run takes up
to 20 minutes. It ends in a report in `docs/playtests/` that lists what the tester achieved and
every obstacle, error, bottleneck and surprise they met.

The game has a new console command set, `playtest`, for this. It reads the game as text, acts
the way a player clicks, and runs game time forward fast. Type `playtest.help()` in the browser
console to see the commands.
